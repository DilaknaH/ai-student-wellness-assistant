# AI Focus & Mental Wellness Assistant

A Streamlit-based AI application that helps students manage study habits, focus, and mental wellness.

## Features
- Predicts student performance using ML
- Analyzes stress and mood levels
- Provides personalized feedback
- Visualizes habits using charts
- Saves user data

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas

##  Run Locally
```bash
pip install -r requirements.txt
streamlit run app_ui.py
````

##  Purpose

This project focuses on helping students overcome stress, burnout, and lack of focus using AI.
